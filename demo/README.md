# 시연 페이지: 오늘의 카페 메뉴

이 문서는 시연 페이지를 띄우고 세 탭을 순서대로 보여 주는 최소 절차를 기술하는 것을 목적으로 한다.

| 항목 | 내용 |
| ---- | ---- |
| 상태 | 프로토타입 (UX 검토 중) |
| 구성 | `www/` 페이지·사진 · `backend/backend.c` 시연 전용 메뉴 백엔드 · `routes.conf` `-c` 설정 |
| 포트 | 서버 8080 · 백엔드 A 8001 · B 8002 · 502용 빈 포트 8009 |

## 1. 실행

저장소 루트에서 한 명령으로 띄운다. Docker와 `curl`이 필요하다. 서버와 백엔드 A·B는 비root Linux 컨테이너 안에서 매번 최신 소스로 빌드한다.

```sh
./demo/run.sh            # 시작 → 준비되면 http://127.0.0.1:8080/ 출력
./demo/run.sh status     # 상태와 응답 확인
./demo/run.sh stop       # 정지·컨테이너 삭제
```

- 브라우저에서 `http://127.0.0.1:8080/`을 연다. `#network`, `#stress`를 붙이면 해당 탭으로 바로 연다.
- 8080이 사용 중이면 다른 포트·이름으로 띄운다: `./demo/run.sh --name mws-demo-2 --port 18080` (status·stop에도 같은 `--name`·`--port`).
- `run.sh`가 만들지 않은 같은 이름 컨테이너나 사용 중인 포트는 건드리지 않고 이유를 출력한 뒤 멈춘다.
- 저장소는 읽기 전용으로 붙이고 빌드 산출물은 컨테이너 안 `/tmp`에만 만든다. 이미지 `mini-webserver-dev`가 없으면 처음 한 번 만든다.

## 2. 시연 순서

| 탭 | 조작 | 보여 줄 것 |
| -- | ---- | ---------- |
| 서비스 체험 | `메뉴 불러오기` → `새로고침` 몇 번 | 사진은 서버, 메뉴는 백엔드. 응답한 인스턴스가 바뀌어도 메뉴가 같다 |
| 서비스 체험 | `메모 보내 보기` 펼쳐 보내기 | `/echo`가 같은 바이트를 돌려준다(저장 없음) |
| 통신 보기 | 최근 기록에서 한 건 고르기(사진은 `사진 요청 N건`을 펼침) | 그 요청의 경로, 보낸 머리와 받은 머리, 메뉴면 백엔드에 도착한 요청(`/api/menu` → `/menu`) |
| 장애와 동시성 | `두 요청 동시에 보내기` | 3초 걸리는 요청 중에도 사진이 먼저 끝난다 |
| 장애와 동시성 | 502·504 `요청 보내기` | 502는 바로, 504는 약 5초 뒤 |

- 통신 보기는 관찰만 한다. 이 페이지를 연 뒤 서비스 체험 탭에서 보낸 요청(최근 활동 20개)만 보이고, 새로고침하면 사라진다.

터미널 수동 장면 (선택):

- 백엔드 하나 끄기: `docker exec mws-demo pkill -f '^/tmp/demo-backend 8002'` → `새로고침`을 여러 번 누르면 일부가 502가 된다. 서버는 다른 백엔드로 다시 보내지 않는다. 되살리기: `docker exec -d mws-demo /tmp/demo-backend 8002 B`
- 중단과 종료: `curl -m 1 'http://127.0.0.1:8080/api/slow?ms=3000'` 뒤 페이지가 계속 동작하는지 본다 → `docker stop mws-demo` → `docker logs mws-demo | tail -3`에서 `서버 종료` 확인 → `./demo/run.sh stop`으로 정리.
- 와이어 원문: `curl -v http://127.0.0.1:8080/api/menu`

알아 둘 것:

- A·B 순번은 `/api/` 요청 전체가 함께 쓰므로, 다른 `/api/` 요청이 끼면 순서가 밀린다.
- 백엔드는 `Host`, `Connection`, `Content-Type`, `Content-Length`, `Accept`, `X-Demo-Trace`만 되돌려 보여 주고, 나머지 머리는 개수만 센다.
- 시연 백엔드 경로: `/menu`, `/inspect`, `/identity.json`, `/slow?ms=N`(최대 10초).

## 3. 중단

- `./demo/run.sh stop` (다른 이름으로 띄웠다면 `--name` 함께). 이 스크립트가 만든 컨테이너만 멈추고 지운다.
