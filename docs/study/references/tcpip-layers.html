라우터는 왜 끝까지 안 올라가나

라우터의 일은 "어느 쪽으로 보낼까"뿐

  • 그 판단에는 도착 IP 주소만 있으면 충분
  • 그래서 인터넷 계층까지만 열어 보고 바로 내려보냄
  • 덕분에 빠르고, 안에 든 게 HTTP든 게임이든 상관없이 중계
  • TCP 연결, HTTP 해석은 양 끝 컴퓨터만 함 → 우리가 만드는 웹서버의 일

이 과제와의 연결

  • 라우터는 인터넷 계층까지만 올라가지만, 프록시는 HTTP 계층까지 올라가서 내용을 읽고 판단해요. 그래서 경로(/api)를 보고 라우팅할 수 있어요.
  • 웹서버 코드는 맨 위 HTTP 데이터만 다뤄요. 그 아래 봉투들은 OS가 씌우고 벗겨 줘요.
