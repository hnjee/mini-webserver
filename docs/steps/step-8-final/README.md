## 1. 요구사항

- 현재 브랜치 구현에만 Step 1~7의 **현행** 완료 기준을 다시 적용하고 결과를 기록한다. 대체된 옛 기대값은 분리한다.
- 현재 브랜치 구현에 `wrk -t4 -c100 -d10s http://localhost:8080/index.html`을 실행해 결과를 기록한다.
- 다른 팀원 구현과 비교하거나 최종 코드를 선택하지 않는다 (D-73). `DESIGN.md`의 팀 공통 기준은 수정하지 않는다.

## 3. 검증 기록

결과: **현행 TC 112개 재확인, `wrk` 2,342.95 req/s·소켓 오류 0**. 옛 계약 6개는 비적용이다. [독립 검증 보고서](../../../.agent/reviews/step8-verify/report.md)와 [TC별 대조표](../../../.agent/reviews/step8-verify/tc-map.md)는 로컬 전용이다.

| 날짜 | 검증 | 결과 | 확인한 것 |
| ---- | ---- | ---- | --------- |
| 2026-11-26 | 현행 계약 전체 회귀 | 🟢 통과 | 고유 TC 118개 중 현행 112개 새 실행·대체 검증 통과, 과거 에코 계약 6개 비적용. ASan 단위 11개·970개 판정, TSan·실제 HTTP·브라우저·종료 관문 재확인. |
| 2026-11-26 | Step 5·7 완료 기준 | 🟢 통과 | `ab -n 2000 -c 50` 실패 0(-c 없음 14,056.30 / 있음 12,005.52 req/s). 실제 Ctrl+C 뒤 서버 생존·종료 0, ASan 오류 보고 없음·valgrind 0 bytes/오류 0. |
| 2026-11-26 | `wrk` 10초 부하 | 🟢 기록 | 비root Linux, -O2·`-c` 없음: 23,475건·2,342.95 req/s, 소켓 오류 0·비정상 HTTP 응답 0; 전후 GET 200·본문 일치. [원문](../../../.agent/reviews/step8-verify/wrk.raw.txt). |

- **대체된 시험:** TC-1-01~06은 Step 2 이후 에코 서버 시점의 시험이다. TC-2-08은 431, TC-3-18은 405라는 현행 계약으로 확인했다.
- **측정 한계:** `wrk`는 한 번의 10초 측정이다. CPU 고정·반복 측정은 하지 않았으며 옛 `ab` 결과와 직접 비교하지 않는다.
- **증거 범위:** 제품·시험·fixture·빌드 파일 47개의 실행 전후 해시가 일치한다. 검증 중 변경된 HEAD의 내용은 학습 문서 두 개뿐이며, 이 결과는 확인한 제품 소스에 한정된다.

## 4. 막힌 것 / 다음 행동

- 현행 계약 기준 미검증 TC나 차단 항목은 없다. 사람 앞 시연은 아직 하지 않았다. 비교·코드 선택은 D-73에 따라 범위 밖이다.
